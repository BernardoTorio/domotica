# Instalaciones Domóticas · 2MT

Animaciones, tests y documentos del módulo de Instalaciones Domóticas (I.E.S. Trinidad Arroyo, Palencia).

Web: https://bernardotorio.github.io/domotica/

- Raíz: `index.html` (portada), las animaciones (`p1-1.html` … `p1-5.html`, `p2-1.html`, `pnp-npn.html`, `plc-entradas.html`, `plc-salidas.html`, `plc-cronograma.html`) y el test (`test_bloque1.html`). Se quedan en la raíz y no cambian de nombre, para que no cambien los QR.
- `temas/`: apuntes en PDF.
- `practicas/`: enunciados de las prácticas en PDF.
- Solo se suben PDF: nunca `.docx` ni `.zip`.

Las reglas de la web (portada, animaciones, tests y criterios de dibujo) están en [`CLAUDE.md`](CLAUDE.md).
